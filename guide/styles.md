# 加工の種類

セットアップウィンドウの「加工」で選べる加工です。
加工ごとの設定は「加工と表示の詳細設定」で調整します。

<!-- 画像: 同じ写真を5種類の加工で表示した比較 -->

## Basic（そのまま）

写真をそのまま表示します。

| 設定 | 内容 |
|---|---|
| 明るさ・コントラスト・彩度 | 写真の色を調整します |
| 階調の数 | 色の段階を減らします（0 なら減らしません） |
| 色味 | 写真に掛け合わせる色です |

## Duotone（二色刷り）

暗い所をインク A、中間をインク B で刷ります。
明るい所は下のマテリアルの色（Tシャツの布の色など）が見えます。

| 設定 | 内容 |
|---|---|
| インク A・インク B | 2つのインクの色 |
| インク A のしきい値・インク B のしきい値 | どの明るさまでをそれぞれのインクで刷るか |
| 境目のぼかし | インクの境目のなめらかさ |
| 明るい所は下の色を見せる | オフにすると、明るい所を「紙の色」で塗ります |

## Halftone（網点）

暗さに応じた大きさの点で刷ります。
点の間は下のマテリアルの色が見えます。

| 設定 | 内容 |
|---|---|
| 横に並ぶ点の数 | 網の細かさ |
| 網の角度 | 点の並ぶ向き |
| 点の太り | 点の大きさの調整 |
| インクの色 | 点の色 |

## Mono（一色刷り）

しきい値で白黒に分け、暗い所だけをインクで刷ります（ステンシル風）。

| 設定 | 内容 |
|---|---|
| インクの色 | 刷る色 |
| しきい値 | どの明るさまでを刷るか |
| 反転 | 明るい所を刷るようにします |
| ディザで階調を出す | 点の粗密で中間の明るさを表します |

## Pixel（ドット絵風）

画素を大きくし、色数を減らします。

| 設定 | 内容 |
|---|---|
| 横の画素数 | ドットの細かさ |
| 色の段階数 | 色を何段階に減らすか |
| 彩度 | 色の鮮やかさ |

## どの加工にもある設定

| 設定 | 内容 |
|---|---|
| デフォルト画像にも加工をかける | オフ（既定）では、デフォルト画像は加工せずに表示します |
| マスク | 写真の上での形を白黒の画像で指定します。白い所だけ表示します。丸や角丸に切り抜くときに使います |
| 不透明度 | 写真全体の濃さ |
| ライティングの影響 | 0 にすると、ワールドの明るさに関係なく同じ明るさで表示します |

加工は自分で作ることもできます。[加工シェーダーを作る](../customize/shader)を参照してください。
