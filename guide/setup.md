# セットアップ

設定はすべて、セットアップウィンドウで行います。
Unity のメニューの **Tools > PICKTURE > Setup** で開きます。

<!-- 画像: セットアップウィンドウの全体 -->

ウィンドウは4つの段に分かれています。
各段の見出しの右に、その段の状態が出ます。

| 表示 | 意味 |
|---|---|
| 完了 | 設定が済んでいます |
| 設定が必要です | 設定が足りないか、反映されていない設定があります。段を開くと、何をすればよいか書いてあります |
| 未設定 | まだ設定していません |

## 0. アバターを選ぶ

Hierarchy でアバターのルート（VRC Avatar Descriptor が付いたオブジェクト）を選ぶか、ウィンドウの「アバター」の欄に指定します。

## 1. カメラ

手に持って使うカメラをアバターに追加し、撮影する画像の縦横比と解像度を決めます。

1. **カメラを追加して自動で配置** を押します。
   アバターの中に `PICKTURE` が追加され、手のボーンの位置から持ち位置が自動で決まります。
2. 持ち位置がずれていたら、**右手の持ち位置**・**左手の持ち位置** を押して選び、Scene ビューで動かします。
   詳しくは[持ち位置を調整する](../customize/grip)を参照してください。
3. 「撮影画像」で、縦横比と解像度（長辺の画素数）を選びます。

<!-- 画像: 1. カメラの段 -->

| 設定 | 内容 |
|---|---|
| 縦横比 | 16:9、3:2、4:3、1:1、3:4、2:3、9:16、またはカスタム |
| 解像度（長辺） | 256〜1024 px。表示する場所の大きさに合わせて選びます。大きいほどくっきりしますが、テクスチャのメモリが増えます |
| 画角（縦） | 写る範囲。小さいほど望遠になります |

::: info 「設定を反映する」が出たとき
撮影画像の設定を変えると、撮影用のテクスチャや表示用マテリアルを合わせ直す必要があります。
警告が出たら **設定を反映する** を押してください。
:::

## 2. 表示する場所

写真を表示する場所を、メッシュとマテリアルスロットで選びます。
複数追加できます。

1. **＋ 表示する場所を追加** を押します。
2. 「メッシュ」と「マテリアルスロット」を選びます。
3. 「加工」を選びます（あとで変えられます）。
4. **追加** を押します。

<!-- 画像: 2. 表示する場所の段（一覧と追加フォーム） -->

表示用のマテリアルは、アップロードするときにその場所へ重ねます。
元のメッシュやマテリアルは変更しません。
エディタでは NDMF のプレビューで、アップロード後と同じ見た目を Scene ビューで確認できます。

一覧の行を選ぶと、次の「3. 表示位置と加工」でその場所を設定できます。
「削除」を押すと、その場所への表示をやめます（作ったマテリアルは `Assets/PICKTURE/` に残ります）。

## 3. 表示位置と加工

一覧で選んだ場所について、写真をどこに出すかと、どう加工するかを決めます。

### 加工とデフォルト画像

- **加工**：写真の加工のしかたです。種類は[加工の種類](./styles)を参照してください。
- **デフォルト画像**：まだ撮影していないときや、カメラが見えない相手の画面に表示する画像です。未指定なら、そのときは何も表示しません。

### 表示位置

方式を2つから選びます。

| 方式 | 向いている場所 |
|---|---|
| UV の矩形 | 表示したい部分が UV の上で1つのまとまりになっている場所（Tシャツの前身頃など） |
| 投影（Remap） | UV が細かく分かれている場所、曲面にまっすぐ写真を出したい場所 |

- **UV の矩形**：テクスチャの上に出る矩形をドラッグして、位置・大きさ・回転を決めます。
- **投影（Remap）**：Scene ビューで投影用の箱を動かし、**この場所に表示** を押します。

それぞれの詳しい使い方は[表示位置を決める](../customize/placement)を参照してください。

### 加工と表示の詳細設定

折りたたまれた「加工と表示の詳細設定」では、加工ごとの色やしきい値、不透明度、ライティングの影響、マスクなどを調整できます。

## 4. テスト（エディタ）

エディタ上で撮影して、表示を確かめます。

- **撮影**：今のカメラの位置から撮影し、Scene ビューのプレビューに表示します。
- **写真を消す**：撮影前の状態（デフォルト画像）に戻します。

確認できたら、いつもどおりアバターをアップロードしてください。
