# PICKTURE とは

PICKTURE は、VRChat のアバターに持たせるカメラギミックです。
アバターが持ったカメラで撮影すると、その写真がアバターの決めた場所（Tシャツの胸など）に表示されます。

<!-- 画像: 撮影して胸に表示されるまでの流れ（3コマ程度） -->

## できること

- エクスプレッションメニューからカメラを右手・左手に持つ、その場に固定する、しまう。
- メニューのボタンで撮影する。5秒のセルフタイマーも使える。
- 撮った写真を、アバターのメッシュの好きなマテリアルスロットに表示する。複数の場所にも表示できる。
- 写真を加工して表示する（そのまま、二色刷り、網点、一色刷り、ドット絵風）。
- まだ撮影していないときや、カメラが見えない相手には、デフォルト画像を表示する。

## 導入の流れ

導入はすべて Unity の上で行います。
アバターの改変（Modular Avatar を使ったギミックの追加）をしたことがあれば、15分ほどで終わる作業です。
<!-- TODO: 実際にかかる時間を測って直す -->

1. [導入](./install)：必要なツールを入れ、PICKTURE の unitypackage をインポートする。
2. [セットアップ](./setup)：セットアップウィンドウで、カメラの追加、表示する場所、表示位置と加工を決める。
3. アバターをアップロードする。
4. [VRChat で使う](./usage)：メニューからカメラを持って撮影する。

::: warning 撮影はアバターのカメラで行います
写真はアバターの中のカメラで撮影し、アバターの上にだけ表示します。
VRChat の写真フォルダへの保存や、インスタンスを移ったあとの写真の保持はできません。
:::

## 購入前に確かめておきたいこと

- 表示する場所は、メッシュのマテリアルスロット単位で選びます。表示位置は、そのスロットの UV の上の矩形で決めるか、投影用の箱で決めます。UV が細かく分かれているメッシュでは、投影用の箱を使うほうが簡単です。詳しくは[表示位置を決める](../customize/placement)を参照してください。
- 周りの人の画面では、その人のクライアントがその場で撮影します。動いている被写体は、人によって少し違う写真になります。詳しくは[写真の見え方と同期](./sync)を参照してください。
- 同期するパラメータは約 9 bit です。
