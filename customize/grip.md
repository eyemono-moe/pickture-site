# 持ち位置を調整する

「右手に持つ」「左手に持つ」を選んだとき、カメラは `Grip_R`・`Grip_L` の位置と向きに付きます。
カメラが手からずれる、向きがおかしいときは、この2つを動かします。

## 手順

1. セットアップウィンドウの「1. カメラ」で、**右手の持ち位置** か **左手の持ち位置** を押します。Hierarchy で `Grip_R` か `Grip_L` が選ばれます。
2. Scene ビューで位置と回転を調整します。
   - `Grip` の +Z（青い矢印）が、レンズの向く方向です。
   - Scene ビューでは、カメラは右手の持ち位置に置かれています。<!-- TODO: Grip_R を動かしたときにエディタ上でカメラが追従するか確かめて書き直す -->
3. 左手の持ち位置も同じように調整します。

<!-- 画像: Grip_R を選んで Scene ビューで回転させているところ -->

::: tip 最初からやり直す
**ボーンの位置から配置し直す** を押すと、手のボーンの位置から持ち位置を決め直します。
調整した位置は失われます。
:::

## 「その場に固定」の位置

「その場に固定」は、そのとき持っていた手の位置で固定します。
カメラをしまっていたときは、右手の持ち位置で固定します。
固定する位置を別に決める設定はありません。
