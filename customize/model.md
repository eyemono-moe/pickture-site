# カメラのモデルを差し替える

カメラの見た目は `PICKTURE/Camera/Model` の中身です。
ここを好きなモデルに差し替えられます。

## 手順

1. `Camera/Model` の中にある既定のモデル（`camera`）を非アクティブにするか、削除します。
   Prefab のインスタンスなので、削除するときは Unity の確認に従ってください。
2. 用意したモデルを `Camera/Model` の子にします。
3. モデルの位置・回転・大きさを調整します。`Camera` の原点がカメラの中心、+Z がレンズの向きです。
4. `Camera/Lens` を、新しいモデルのレンズの前面に動かします。+Z（青い矢印）が撮影する方向です。

<!-- 画像: Lens をモデルのレンズの前に合わせたところ -->

::: warning Lens はモデルの外に出す
`Lens` がモデルの中に埋まっていると、モデルの内側が写ってしまいます。
レンズの面より少し前に置いてください。
:::

## 既定のモデルについて

- 大きさは約 11 × 7.4 × 3.5 cm です。
- シェーダーは lilToon です。色を変えるときは、マテリアルを複製してから変えてください。

## 撮影に写らないもの

撮影するカメラには、次のものは写りません。

- VRChat のメニュー、ネームプレートなどの UI
- 持っている本人の頭（一人称視点で縮んでいる頭）
