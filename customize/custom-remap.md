# Remap テクスチャを自分で作る

Remap テクスチャは、表示する場所の各画素に「写真のどこの色を出すか」を書いたテクスチャです。
投影用の箱から焼き込む代わりに、自分で描いたテクスチャを使えます。

たとえば、服のカラーチェンジ用のマスクを元にすると、**写真の中の色に変わる服**を作れます。

## 使い方

1. セットアップウィンドウの「3. 表示位置と加工」で、表示位置を **投影（Remap）** にします。
2. **テクスチャを指定する** を選びます。
3. 「Remap テクスチャ」に、用意したテクスチャを指定します。
4. 読み込み設定の警告が出たら、**読み込み設定を直す** を押します。

## テクスチャの描き方

表示する場所の UV に合わせて描きます（そのメッシュのテクスチャと同じ配置です）。

| チャンネル | 意味 |
|---|---|
| R | 写真の横の位置。0 が左端、1 が右端 |
| G | 写真の縦の位置。0 が下端、1 が上端 |
| B | 使いません |
| A | 表示の濃さ。0 で表示しません |

黒（R と G がどちらも 0）の画素にも表示しません。
写真を出したくない所は、黒か透明で塗ってください。

### 例

| 塗り方 | 見た目 |
|---|---|
| 一色で塗る（例：R = 0.5、G = 0.5） | 写真のその1点（例：真ん中）の色で塗られます |
| 横方向に R を 0→1 のグラデーションで塗る | 写真の横一列の色の並びが出ます |
| R と G をそれぞれ横と縦のグラデーションで塗る | 写真がそのまま貼られます（UV の矩形と同じ） |
| A を服の裾に向けて 1→0 にする | 写真の色が裾に向かって薄くなります |

<!-- 画像: Remap テクスチャの例と、それを使った見た目 -->

::: tip 色を拾う場所を決める
写真の真ん中は、構図の主役が写りやすい場所です。
服の主な部分を写真の真ん中近く、差し色の部分を写真の端の近くに割り当てると、景色の色と被写体の色の両方を拾えます。
:::

## 読み込み設定

Remap テクスチャは「色」ではなく「位置」を表すので、次の読み込み設定が必要です。
**読み込み設定を直す** を押すと、まとめて設定します。

| 設定 | 値 | 理由 |
|---|---|---|
| sRGB (Color Texture) | オフ | 値が変換されて、位置がずれるため |
| Compression | None | 圧縮で値が崩れるため |
| Generate Mip Maps | オフ | 遠くで隣の画素と混ざるため |
| Non-Power of 2 | None | 大きさが変わると、画素の位置がずれるため |

::: warning 同じテクスチャをほかで使っているとき
読み込み設定を直すと、そのテクスチャを使っているほかのマテリアルの見た目も変わります。
カラーチェンジ用のマスクをそのまま使うときは、テクスチャを複製してから指定してください。
:::

## 精度について

- 8bit のテクスチャ（PNG など）では、写真の位置は 256 段階になります。色を拾う使い方なら十分です。
- 写真をなめらかに貼りたいときは、16bit の PNG か EXR で保存してください。
- 塗り分けの境目では、隣の色の領域と混ざらないように処理しています。境目に写真の別の場所の色が出ることはありません。
