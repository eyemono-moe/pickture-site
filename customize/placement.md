# 表示位置を決める

写真を表示する場所（メッシュのマテリアルスロット）の上で、写真をどこに出すかを決めます。
セットアップウィンドウの「3. 表示位置と加工」の「表示位置」で、方式を選びます。

| 方式 | 仕組み | 向いている場所 |
|---|---|---|
| UV の矩形 | テクスチャ（UV）の上に、写真を貼る矩形を置く | 表示したい部分が UV の上で1つのまとまりになっている場所 |
| 投影（Remap） | 箱から写真をメッシュに投影し、結果をテクスチャに焼き込む | UV が細かく分かれている場所、曲面にまっすぐ出したい場所 |

## UV の矩形

ウィンドウに、表示する場所のテクスチャと、写真を貼る矩形が表示されます。

| 操作 | 動作 |
|---|---|
| 矩形の中をドラッグ | 移動 |
| 角をドラッグ | 大きさの変更（中心は固定） |
| 上の丸をドラッグ | 回転（Shift で 15° 刻み） |

- **撮影画像の縦横比を保つ**：オンなら、矩形は撮影画像と同じ縦横比になります。UV が歪んでいるメッシュでは、オフにして矩形を引き伸ばすと、見た目の縦横比を合わせられます。
- **UV を表示**：メッシュの UV の線を重ねて表示します。

<!-- 画像: UV の矩形の編集画面 -->

UV の島の境目をまたぐと、写真がそこで切れたりずれたりします。
そのときは投影（Remap）を使ってください。

## 投影（Remap）

投影用の箱から、メッシュに写真を投影します。
投影の結果は Remap テクスチャ（メッシュの各点に「写真のどこの色を出すか」を書いたテクスチャ）に焼き込みます。
UV がどう分かれていても、Scene ビューで見たとおりの位置に写真が出ます。

### 手順

1. 「投影用の箱から作る」を選びます。
2. 「投影用の箱」の **作成** を押します。アバターの中に箱が作られます。
3. Scene ビューで箱を動かし、拡大縮小と回転で位置を決めます。
   - 箱の手前（×印の面）から奥（+Z）に向けて写真を投影します。
   - 箱の外の面と、手前を向いていない面には表示しません。
4. **箱の縦横比を撮影画像に合わせる** を押すと、写真が歪みません。
5. **この場所に表示** を押します。

<!-- 画像: 投影用の箱を Scene ビューで動かしているところ -->

**箱を動かしたら自動で更新する** をオンにすると、箱を止めて少しすると自動で焼き込み直します。

### Remap テクスチャの大きさ

「Remap テクスチャの大きさ」は、写真が出る範囲の長辺の画素数です。
大きいほど写真の縁がなめらかになりますが、テクスチャのメモリが増えます。
多くの場合は 512 で足ります。

### 注意

- 投影用の箱はエディタ専用です。アップロードしたアバターには含まれません。
- 焼き込んだときのポーズで投影します。メッシュの形を変えた（シェイプキーを変えた）ときは、焼き込み直してください。
- 左右対称のメッシュなど、UV を共有している面には、同じ写真が出ます。焼き込んだときに警告が出ます。

## マスクで形を切り抜く

「加工と表示の詳細設定」のマスクに白黒の画像を指定すると、写真を丸や角丸などの形に切り抜けます。
マスクは写真の上での形です（白い所だけ表示します）。

服の上でのグラデーションなど、メッシュの上での形で濃さを変えたいときは、[Remap テクスチャを自分で作る](./custom-remap)方法を使います。
