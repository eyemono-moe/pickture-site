# 改変の概要

PICKTURE は、カメラの見た目や持ち位置、写真の出し方を変えられるように作っています。
このページでは、改変するときに知っておくとよい構成をまとめます。

## アバターに追加されるもの

セットアップウィンドウの「カメラを追加して自動で配置」で、アバターの中に次のオブジェクトが追加されます。

```
PICKTURE            … Modular Avatar のコンポーネント（アニメーター、パラメータ、メニュー）
├─ AnimDummy        … アニメーション用のダミー。消さないでください
├─ Grip_L / Grip_R  ★持ち位置。手のボーンに追従し、持ったカメラがここに付きます
├─ Camera           ★カメラ本体。しまっている間は非アクティブです
│   ├─ Model        … カメラの見た目。自由に差し替えられます
│   └─ Lens         ★撮影の視点。位置と前方向（+Z）から撮影します
│       └─ Marker   … 撮影の判定に使います。消さないでください
└─ Menu             … エクスプレッションメニュー
```

★の付いたオブジェクトは、名前と親子関係を変えないでください。
アニメーションがこの名前で参照しています。
位置・回転・大きさは変えてかまいません。

## 改変するときの注意

- PICKTURE のアニメーターのレイヤーは Write Defaults オフで動きます。アバターの FX が Write Defaults オンでも、そのまま使えます。
- 表示用のマテリアルとテクスチャは `Assets/PICKTURE/<アバター名>/` に作られます。同梱の Prefab やマテリアルは直接編集せず、アバターの中の PICKTURE（Prefab のインスタンス）を編集してください。
- 表示用のマテリアルの値の一部（撮影画像、表示位置など）は、セットアップウィンドウが管理しています。マテリアルのインスペクターでは確認用に表示するだけです。
